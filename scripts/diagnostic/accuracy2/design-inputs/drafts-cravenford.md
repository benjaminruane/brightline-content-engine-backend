## The twin subset

Twelve statements. Each takes the exact sentence of a shape's ugly-source instance and
plants it, word for word, against the clean twin of that same document. Same claim,
same source content, only the extraction damage differs.

```
FROM K-D1 against K2   S16 S14 S01 S04 S15
FROM K-D2 against K2   S03 S08 S09 S12
FROM C-D1 against C2   S02 S13
FROM C-D2 against C2   S07
```

**TWELVE, NOT SIXTEEN.** Four shapes have no single-source ugly instance to twin:
S05 and S06 need two sources, S10 needs the either/or that only the memo and the
letter carry, and S11's hedges live in the same two documents. Those four are excluded
and the twin comparison is reported over twelve shapes, not sixteen.

**SCORED SEPARATELY. NEVER IN THE HEADLINE CATCH DENOMINATOR.** The ugly half of each
pair is already counted once in the main 48. The clean half exists only to answer
whether the same fault survives the mangling.
